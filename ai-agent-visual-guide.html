第 1 章 · AI Agent 入门

网络身份：定义层原点。整本书的对象边界、术语入口和中心公式都从这里展开。

展区：定义层 类型：起点节点 连接度：高

Agent = LLM + 上下文 + 工具，是整张图的中心坐标。

该节点向后分裂出两条主线：一条进入系统构建层，另一条进入行动与协作的扩展层。

它不是内容密度最高的节点，但它是所有后续节点的命名基础。

线型说明

实线表示直接依赖、局部展开和近距离结构延续。虚线表示远距离呼应、跨层投射或后期回收。

图面观察

第 2 章位于中心，第 5 章承担桥梁角色，第 10 章收束多条支线。整本书的网络重心更偏“构建层”，而不是“应用层”。

结构坐标系

把全书从“章节顺序”转换为“结构维度”。每张卡片都是一根分析轴，用来观察知识如何分层。

对象轴

从 Agent 本体，到上下文、工具、代码、记忆、评估、训练，再到多主体系统。对象层层外扩。

时间轴

从单次决策点的上下文组织，走向跨会话记忆，再走向持续评估、训练和演化，最后进入长期协作系统。

空间轴

从模型内部决策，扩展到文件系统、工具生态、GUI、语音、机器人和多 Agent 组织空间。

控制轴

从提示与循环控制，走向工具接口、权限边界、评估基准、训练奖励和协作治理。

主题流

这些不是章节标题，而是跨章节反复穿行的母题。它们在图中像暗流一样，把不同展区联结起来。

系统化

书中持续把 Agent 从“模型能力”转写为“系统能力”。

上下文主导

上下文组织是整本书里最强的中心张力。

工具化行动

工具让语言系统进入可执行世界，构成行动接口层。

测量驱动

评估不是附录，而是训练、优化和演化的前提设施。

权重外增长

记忆、代码、技能和工具创造组成另一条增长路径。

组织化扩展

从单体走向多模态、多主体和社会化结构，是末端展区的共同方向。

关系流向

用三条长流观察内容迁移：定义如何变成工程，工程如何变成能力，能力如何变成现实系统。

定义 → 构建

第 1 章建立对象定义，第 2–5 章把这个对象工程化，形成上下文、记忆、工具和代码四块主骨架。

构建 → 形成

第 6–8 章不是另起炉灶，而是在既有骨架之上回答“怎样衡量它、训练它、继续增强它”。

形成 → 扩展

第 9–10 章把前面的系统能力投向更复杂环境：实时、多模态、协作、组织和治理。
