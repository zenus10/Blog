# 设计规范

## 设计理念

### 高效

>- 1. 效率：尊重用户时间，适应用户行为，尽可能节约用户的时间；费茨定律#
>- 2. 简单：如无必要，勿增实体，去掉不必要的干扰项；奥卡姆剃刀#
>- 3. 一致：同一事物和同类操作的视觉表达、交互以及文案用语要保持一致；  
>- 4. 清晰易懂：信息层级，语义，操作重点清晰明确，减少无关信息，体现简洁美感；席克定律#
>- 5. 重点突出：增强重点数据与其他信息的对比关系，突出每个容器内重点信息/数据；信噪比#
>- 6. 最小成本：尽可能为用户节省操作成本，为技术减少非必要的实现成本；

### 友好

>- 以人为本：从用户角度出发，提供必要的信息提示（可视&易取）；
>- 及时反馈：对用户的操作给予及时适当的反馈，满足用户对操作相应的预期；多尔蒂门槛#
>- 贴近现实：使用用户语言而不是开发者语言，贴近生活实际而不是学术概念；MAYA法则#
>- 容错：给用户明确的错误信息，并协助用户方便的从错误中恢复工作；
>- 愉悦：给予适当的正向激励以及情感传递，打造精神愉悦的使用体验；

### 严谨

>- 科学：基于调研，反馈，数据等科学的方法，让设计有迹可循；
>-  严谨：设计中使用的每一个元素都是经过仔细的斟酌和严谨的思考；
>- 秩序性：利用亲密性及对齐原则将信息有序的排列起来，实现信息的条理性与组织性；格式塔原理#
>- 可度量：用科学的度量方法，验证设计的有效性；

### 稳定

>- 稳定：充分考虑各设备的兼容与拓展，打造稳定的使用体验；
>- 防错：有预防用户出错的措施，关键操作有确认提示，及早消除误操作；
>- 安全：对用户关系的数据和隐私保护，对敏感操作设置防护；
>- 可控：根据场景给予用户操作建议/提示，但不会替用户进行决策；

### 开放

>- 个性化：针对不同的用户群体，尊重他们的习惯，有相对应偏向性的设计；
>- 可拓展：充分考虑多语言，多平台，多端的适配与拓展；
>- 开放：秉持开放心态，吸收不同意见，不断迭代无限循环成长；
>- 包容：为更多有需要的群体设计，将无障碍设计考虑其中；

## 设计语言

### 颜色

1. 主题色

**定义：**
主题色是用于体现产品特性和传播产品特性最直观的元素，最直观展现在产品的视觉识别度，并在很大程度上决定产品的基调和风格。主要应用场景为：关键行动点，操作状态，重要信息高亮等。

**使用场景：**
使用主题色增强视觉差异性，突出主要功能。

2. 中性辅助色

**定义：**

中性辅助色又称为灰阶色系，主要用于背景，描边，文字，分割线等。选择中性色时需要考虑深、浅背景下的明度对比差异性。合理地选择中性色能够令页面信息具备良好的主次关系，保障界面元素的可识别性。从#000000 到 #FFFFFF 共分 14 个梯度，用于辅助信息传达，突出信息层级等。

此外各层级的灰黑色中可以加入一定的颜色倾向，以突出主题氛围。

对比度可以通过公式计算，该公式的比率范围为1:1（无对比度，例如黑色背景上的黑色文本）到21:1（最大对比度，例如白色背景上的黑色文本）。

**最佳展现：**

色彩对比度 7 : 1 ，常规大小的文本的“增强”对比度。

色彩对比度 4.5 : 1 ，常规尺寸文本（14pt+字号）的最小对比度。

色彩对比度  3 : 1 ，“大比例尺文本”（18pt或14pt粗体或更大）及图像视觉的最小对比度。

**使用场景：**

深色中性色适用于标题、正文和重点信息；中间色阶适用于次要文字、图标和普通描边；浅色阶适用于背景、分割线、禁用状态以及悬浮状态。使用时应根据内容重要程度选择相应色阶，避免信息层级混乱。

3. 功能色

**定义：**

功能色是一组较为特殊的颜色，用来表达信息及操作的状态，例如：成功，失败，出错，告警，连接等，通常需要符合大众用户对色彩的普遍性认知。

**使用场景：**
功能色经常通过色彩来传达不同感受、如红色-危险、黄色-警示、绿色-成功。

4. 辅助色

**定义：**

辅助色共 12 份色相，每个颜色根据 HSL 曲线递增或递减，可拓展出 9 个衍生色，共计 120 色

**使用场景：**

辅助色主要用于图表、数据可视化、标签、头像、装饰元素以及需要区分多个对象或信息类别的复杂场景。使用时应避免辅助色抢占主题色的视觉权重，并保持同类信息的颜色语义一致。
 
### 圆角
 
**基础定义：**
对组件给予圆角，符合友好愉悦、稳定可靠的设计理念。

**使用说明：**
1. 尺寸越小，采用的圆角度数越小，最小度数为2px；
2. 中尺寸组件采用4px的圆角度数；
3. 视觉面积较大组件使用8px的圆角度数；

**类型：**

2px 场景：2px圆角使用的场景多为组件之中，常见的组件有“复选框”“标签”等小组件。


4px 场景：4px圆角使用较多，例如常规使用的“输入框”，“按钮”，“下拉”等


8px 场景：8px圆角适用于大卡片，或者大面积场景，例如“卡片”


### 字体

**基础定义：**
良好的字体排版不仅让界面看起来有秩序，还有助于信息内容的传达，提升用户的阅读体验。字体是组成产品界面的重要元素，也直接影响了用户的阅读体验及工作效率。


**字体家族：**

优先使用系统默认界面字体，同时也提供利于屏显的备用字体库
~~~
font-family：Inter,-apple-system,BlinkMacSystemFont,Segoe UI,PingFang SC,Hiragino Sans GB,Microsoft YaHei,Helvetica Neue,Helvetica,Arial,sans-serif;
~~~

**字阶与行高：**
字阶和行高决定着一套字体系统的动态与秩序之美。字阶是指一系列有规律的不同尺寸的字体。行高可以理解为一个包裹在字体外面的无形的盒子；

- 行高统一遵循 +8 的梯度变化，好记、易用；
- 主字体使用 14 号字，保证在多数常用显示器上的用户阅读效率最佳。

**字重：**

字重的选择同样基于秩序、稳定、克制的原则。多数情况下，只出现 regular 以及 medium 的两种字体重量，分别对应代码中的 400 和 500。在英文字体加粗的情况下会采用 semibold 的字体重量，对应代码中的 600。


**字体颜色：**

中性色字体，共有5个梯度。语义色字体，默认提供基础4色

**行长：**

在 长文本 的情况下，为了获得良好的阅读体验，文本宽度建议范围：650px-750px，英文正文的理想行长是每行 40-60 个字符。

太宽 —— 如果一行文本太长，读者的眼睛将很难集中在文本上。这是因为线的长度使得很难测量线的起点和终点。此外，在大文本块中继续到正确的行可能很困难。

太窄 —— 如果一条线太短，眼睛将不得不经常向后移动，打乱了读者的节奏。

### 阴影

**基础定义：**

阴影来源于现实生活中光遇到无法穿透的介质时产生暗区域，反映物体与物体之间距离的物理现象。在界面中，我们往往通过阴影来模拟元素之间的空间关系，帮助用户快速理解界面中元素的空间关系，更容易理解界面内容。

**阴影说明：**
1. x，y，z模拟物理世界光源形成，光照从上至下，中间为不透明介质；
2. 阴影的虚实，大小，由物体对应的高度不同而不同；
3. 光源高度一致的情况下，物体越低阴影越实越清晰，随着物体在Z轴的高度升高，阴影边缘越大越模糊。
4. 将阴影分为4个等级，从0-3，代表物体的高度逐渐升高。


**阴影级别：**

- 0级阴影:物体高度为0，投影与物体重合，适用于容器内元素，例如：输入框，搜索框，按钮，文本区域等；

- 1级阴影:物体高度为1，物体位于低层级，例如：卡片，topbar，左导航等；

- 2级阴影:物体高度为2，物体位于中层级，阴影可以向下覆盖低层级，例如下拉面板，成功提示反馈等；

- 3级阴影:物体高度为3，物体位于高层级，阴影覆盖页面，例如抽屉，弹窗。
移和模糊半径的递增表现高度变化。

**阴影方向：**

不同的阴影高度可以代表不同的元素层级，而不同的阴影方向也是用在不同的地方：

- 阴影向下（默认）：用于大部分组件，也是默认的场景。
- 阴影向上：一般用于底部导航或吸底固定的模块上。
- 阴影向左：一般用于抽屉组件或表格固定列。
- 阴影向右：一般用于导航菜单、抽屉组件或表格固定列。

## 组件规范

### 按钮

**基础定义：**
来源于生活中的物理控制元件，主要用于触发一个操作，响应用户点击行为，触发相应的业务逻辑。
 
**使用说明：**

1. 用于引导用户采取你希望的行为，按钮应该清晰的告知用户当前状态，避免犯错。
2. 按钮字段长度不宜超过 5-8 个中文字符，文案需明确行动指令，可使用动词或动宾结构文案，用户可从按钮上清晰的预测出行为结果。
3. 如果点击按钮不会立即响应，应当显示加载状态，此时按钮不可点击。
4. 相同操作指令的按钮应注意保持字段、样式和摆放位置的统一。
 
**基础构成：**

1. icon：图标可以帮助用户提高按钮识别效率，可放置在按钮左侧或右侧，更强调该功能；
2. 文本：按钮的操作指令，编写按钮文本时，尽量使用户能够通过文本预测到触发当前按钮的结果；
3. 容器：当前按钮的容器，用于承载icon和文本；
 
**类型：**

- 常规按钮
常规按钮有五种类型：主要按钮、次要按钮、默认按钮、文字按钮、虚线按钮

- 图标按钮
图标按钮能帮助用户快速识别操作，不建议多个按钮同时使用图标按钮。

- 危险按钮
用于删除/移动/修改权限等危险操作，一般需要二次确认。

- 按钮组合： 

按钮组合使用时，推荐使用 1 个主操作按钮 + n 个次操作按钮，可以使用ButtonGroup来组合按钮。对于数个并列操作的操作按钮，可将更多操作放置到 SplitButton 中组合使用。

**尺寸布局：**

按钮有大、中、小三种尺寸，中等大小是默认和常见的尺寸。

- 圆角矩形按钮： 

大尺寸：默认宽度根据内容自适应，最小宽度 88px，左右间距 20px。 

中尺寸：默认宽度根据内容自适应，最小宽度 74px，左右间距 16px。 

小尺寸：默认宽度根据内容自适应，最小宽度 60px，左右间距 12px。

- 全圆角按钮： 

大尺寸：默认宽度根据内容自适应，最小宽度 96px，左右间距 24px。 

中尺寸：默认宽度根据内容自适应，最小宽度 82px，左右间距 20px。 

小尺寸：默认宽度根据内容自适应，最小宽度 68px，左右间距 16px。


- Block 按钮宽度： 

将按钮宽度调整为其父容器宽度的选项，可根据业务选用大、中、小三种不同尺寸及不同类型。
